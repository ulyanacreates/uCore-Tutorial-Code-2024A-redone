## 问答作业第6章
1. 在我们的文件系统中，root inode起着什么作用？如果root inode中的内容损坏了，会发生什么？
root inode 是根目录的inode；文件创建、link和unlink等操作都需要通过它定位其他目录项。如果根inode损坏，文件路径或名称将无法用于查找目录项，上述操作也会受阻。

## 问答作业第7章
1. 举出使用 pipe 的一个实际应用的例子。
```
grep "关键字" 文件名 | wc -l
```
若使用cat举例，可以得到：
```
cat file.txt | wc -l
```
2. 如果需要在多个进程间互相通信，则需要为每一对进程建立一个管道，非常繁琐，请设计一个更易用的多进程通信机制。
为了解决多个进程之间通信需要为每一对进程单独建立管道的繁琐问题，可以设计一个基于消息队列的多进程通信机制。可以使用一个集中式的消息队列，所有进程通过队列进行读写操作，实现共享的通信通道，避免逐对建立管道。这样，多个进程可以共享同一个通信通道，实现高效的消息传递，同时避免了为每对进程单独建立管道的复杂性。
